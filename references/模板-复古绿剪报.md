# 模板：复古绿剪报

**样张**：`assets/样张/复古绿剪报.jpg`。用 Seedream 出图时把它放进参考图第一张，照它的版式、配色和装饰出，内容换成这场活动（写法见 SKILL.md「第三步（Seedream）」）。

一句话：橄榄绿旧纸底，顶上一排超大黄色毛笔英文，柠檬黄剪纸色块压两行黑色断笔大字，四角贴复古电视、相机和涂鸦，底下拼黑白和彩色的街景照片

适合：多日营、城市游、跨城研学这类热闹、有好几个看点的活动。

这份设计取自旅游营销工作台的自带模板。2026-10-24 用腾讯云 Seedream 5.0 Pro 按下面的提示词骨架填活动资料出过竖版，中文字全对、版式到位；出完照「验收要点」逐条看。

**照片**：有这场的实拍照片，放进参考图（Seedream 走 `ref_paths`），提示词里写「画面用图一的实拍照片……原样保留，不重画、不加人」，人才像真的。没有实拍照片，AI 画的是示意，人物写成背影、侧身或远景，交付时说清楚“画面里的人和景是 AI 画的示意”。不要让 AI 照着某个真实地名去画地标，冒充去过。

## DNA：换活动也不变

**渲染**：平面拼贴。底是一张带细密噪点和几道浅色竖向划痕的橄榄绿旧纸，像翻拍的老海报；上面贴平涂的柠檬黄色块、白色标签、黑色线条涂鸦，和沿轮廓剪下的实拍照片、复古物件。照片两种处理并排：一张转黑白、高反差，一张保留浓烈的原色；人手和相机是黑白网点印刷的样子。光是平的，不做投影。上段和中段亮（平均亮度约 160/255，绿底加黄块），下段暗（约 114，照片拼贴）。

**构图**

- 焦点：画面上半部正中的柠檬黄色块和里面两行黑色大字，是全画面最亮、对比最强的一块。
- 层次（从下往上）：绿底 → 顶部黄色英文大字 → 复古电视（压住英文下沿）→ 黄色色块 → 标题字、小字 → 箭头标签、星芒涂鸦、相机手（压住色块的三个角）→ 底部照片拼贴。
- 视线：顶部黄色英文（只扫一眼当背景）→ 色块里两行大字 → 色块底下一行小字 → 两侧的电视、相机 → 底部照片。
- 平衡：色块占住中轴，四角各压一样东西把它围住：左上电视、右上箭头标签、左下星芒、右下相机手；下面照片拼贴压底，左边黑白、右边彩色。

层级：大标题 : 英文大字 : 箭头标签 : 小字 ≈ 1 : 1（只当背景纹理）: 0.23 : 0.18。整张四种字：断笔标题字、毛笔英文、细黑体、手写英文。

字的固定写法：

- 大标题：两行，每行一个动作加一个对象（「逛××」「吃××」），每行 3 个字，两行一样长。
- 英文大字：目的地的拼音或英文，全大写。
- 箭头标签：「Go」加目的地拼音，小写。
- 小字一行：「年份出游·地点几日精华路线」这样的一句，十来个字，中间用间隔号。

**装饰**

- 黄色色块：一整块不规则多边形，七八条直边、转角有钝有尖，像用剪刀剪下来的纸；四周一圈白边，宽约画面宽的 0.8%。
- 箭头标签：白色长条，右端剪成箭头尖，左端平切。
- 星芒涂鸦：黑色圆头线条，粗细均匀，线宽约画面宽的 0.8%：中间一颗黑描边的黄色六角星，四周放射十来道短线，五道短线的末端各带一个空心小圆圈，再拖一道长长的弧线往左下，像一朵烟花。
- 复古电视：橙色外壳、墨绿面板，屏幕里是这场的一张照片。
- 相机手：一只黑白网点的手握着一台老式胶片相机，沿轮廓剪下，带一圈毛糙的白纸边。
- 旧报纸：米黄色报纸碎片，印着大号衬线字母和一条黑白网点带，斜贴。
- 照片纸边：黑白照片带白边；彩色照片外圈是白纸边，再套一道黄绿描边（#D5E125）。
- 路牌：偏橙的黄色菱形，黑色弯箭头，下面一根灰蓝的杆子。

## 为什么好看

1. 撞色抓眼：柠檬黄色块压在灰绿底上，明度差很大，黑字压黄约 18:1，划手机的时候一眼就停在标题上。
2. 两层字分工清楚：顶上的黄色英文又大又被切掉一截，只当背景纹理、营造城市感；真正要读的中文全收在黄块里，不抢。
3. 一个剪纸语言贯穿：色块、标签、照片都是剪下来的形状加白边，标题字也是断笔斜切，整张像一本手工剪贴本，统一又有手作感。
4. 四角压东西把视线收进中间：电视、箭头、星芒、相机围着色块，眼睛在里面转一圈才出去。
5. 下暗上亮压得住：底部黑白照片最暗，把画面坐稳，也让上面的黄块更亮；路牌的黄和标题块呼应，把视线从标题带到照片。

## 可变范围：跟着活动变

- 英文大字（{英文}）：这场目的地的拼音或英文，全大写，5–9 个字母最好；字母多了把字缩小，仍是一行铺满、上边切掉一截。
- 大标题（{标题}，分成{标题第一行}和{标题第二行}）：两行，每行 3–4 个字，两行一样长或只差一个字；照「字的固定写法」用「动作加对象」，比如「探古镇／做非遗」。
- 箭头标签：「Go」加拼音小写；没有合适的拼音就写「Let's go」。
- 小字一行（{副标题}）：时间、地点、几天、玩什么，十到十六个字。
- 卖点：0–3 条，用长图里的做法：每条一行黑字压一条柠檬黄高亮条（黄条只比字长一点，几条左端错开），每条 4–10 个字，宁少不编。
- 电视屏幕里放这场的一张照片（地标、场馆），不放样张的照片。
- 照片拼贴（{画面焦点}）：黑白那张放这场的场馆、街景或建筑；彩色那张放最热闹的活动场面，有孩子就放这张里。路牌的箭头方向可以换。

## 容易翻车

- 绿底画成鲜艳的草绿、薄荷绿，或者干干净净没有噪点划痕：旧纸的味道没了。
- 黄色用成暖黄、橙黄：柠檬黄要偏冷、发亮，路牌的黄才是偏橙的。
- 用黄字直接压绿底写要读的字：黄压绿只有约 2.3:1，读不清；要读的字只放在黄块、黄条和白标签上，顶上的黄色英文只当背景。
- 标题字画成普通黑体：没有断笔、斜切，剪贴本的手作感就没了；反过来断得太碎也读不出字。
- 黄色色块画成圆角矩形或规则的对话框：要像剪刀剪的多边形，带白边。
- 四角的东西压到标题字上；底部照片塞太多张，变成一锅粥：照片最多两张加一块路牌。
- 把电视、相机画成新的数码产品：要老式的。

## 提示词骨架

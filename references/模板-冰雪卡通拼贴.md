# 模板：冰雪卡通拼贴

一句话：上面是白色撕纸标题卡，蓝色粗圆体大标题配粉色副标题条和卡通贴纸（套娃、滑雪小人），中间一整张夕阳下的城市地标实拍，下面是带白边的雪山和滑雪孩子剪贴，顶上一排冰挂。

适合：冬季营、冰雪研学、东北和北方城市的多日营；手上有地标或雪景照片的活动。

不适合：夏天户外、室内手工课、讲座。

**样张**：`assets/样张/冰雪卡通拼贴.jpg`（取自 10-20 中亲盟哈尔滨公众号长图第一屏）。这个模板没有文字骨架，用 Seedream 照样张出：样张放进参考图第一张，提示词开头写 SKILL.md「第三步（Seedream）」里那句“只学版式”，再写这场活动的画面和每段字：

- 顶部：一张白色撕纸标题卡，左上一条小粉色标签写着“{城市}”，卡上写着蓝色粗圆体大标题“{标题}”，下面一条粉色色条写着白字“{一句话卖点}”；标题卡四周贴两三个卡通贴纸（和这场有关的小物件）。
- 中间：一整张这场的地标或风景实拍，傍晚暖光，天空有晚霞。
- 下部：带白边的雪山剪贴和一两个在雪地里玩的孩子抠图（有人脸参考就照人脸参考）。

## 验收要点

- [ ] 标题卡在上面、地标照片在中间、雪景剪贴在下面，三段分明
- [ ] 标题、城市标签、副标题的字全对
- [ ] 样张里的“哈尔滨”“冰雪亲子营”“赏冰玩雪，探寻北国人文”没有留下来（除非这场就是这些字）

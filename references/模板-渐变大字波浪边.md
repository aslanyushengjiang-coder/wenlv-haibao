# 模板：渐变大字波浪边

一句话：白底上横着一行粉蓝渐变的超粗大标题，配英文手写字和几样小贴纸；下面一张大照片，上沿剪成起伏的波浪边，压着粉色、黄色两段胶囊标签；底部一道黄色波浪条托着三张小照片

适合：多日营、研学营、海岛和湖边这类明亮清新、有好几张照片可拼的活动。

这份设计取自旅游营销工作台的自带模板。2026-10-24 用腾讯云 Seedream 5.0 Pro 按下面的提示词骨架填活动资料出过竖版，中文字全对、版式到位；出完照「验收要点」逐条看。

**照片**：有这场的实拍照片，放进参考图（Seedream 走 `ref_paths`），提示词里写「画面用图一的实拍照片……原样保留，不重画、不加人」，人才像真的。没有实拍照片，AI 画的是示意，人物写成背影、侧身或远景，交付时说清楚“画面里的人和景是 AI 画的示意”。不要让 AI 照着某个真实地名去画地标，冒充去过。

## DNA：换活动也不变

**渲染**：平面拼贴加实拍。上面三成是干净的白底；大照片是真实摄影，晴天，天空是饱和的深蓝，顺光，颜色鲜艳；照片上沿剪成起伏的波浪，左边直接是白色波浪边，右边先垫一道浅蓝波浪再接照片。标题、胶囊、碎片都是平面的渐变色和纯色，没有投影，只有标题右下一道细细的橙色错位边。底部黄色波浪条是纯色平涂。明暗：上三分之一平均亮度约 223/255（白底），中间约 133（深蓝天空和人），下面约 146。

**构图**

- 上中下三段：上段 y 0–33 白底标题区；中段 y 30–90 大照片，上沿是波浪边；下段 y 85–100 黄色波浪条和一排小照片。左下另贴一张剪成山形、带白边的小照片，木头路牌立在上面（这两样可有可无，见可变范围）。
- 焦点：第一眼是粉蓝大标题，接着是标题下的两段胶囊，再落到照片中间背对镜头、举手欢呼的一群人。
- 视线：从上往下：左上小胶囊 → 大标题 → 两段胶囊标签 → 天空里右侧的两行口号 → 人群 → 底部小照片。
- 平衡：标题横贯；胶囊标签偏右，口号靠右，路牌压左下，走路小人压右下，左右交替。
- 照片：人群背对镜头站在目的地地标前，举手欢呼，人群在照片中下部（y 61–89）；地标往上一直顶到照片上部，后面是大片深蓝天空，口号就写在天上。

层级：大标题 : 英文手写（大写首字母） : 胶囊标签 : 小胶囊 : 口号 : 细英文 ≈ 1 : 0.32 : 0.21 : 0.17 : 0.14 : 0.14（大标题按 14% 算）。整张四种字：超粗方黑体（标题）、圆润粗黑体（胶囊、小胶囊）、常规黑体（口号）、英文（花体手写、细无衬线）。

字的固定写法：

- 小胶囊：一句邀请，「我在 + 地名 + 等你」这样，5–7 个字。
- 英文手写：两个英文单词，说主题。
- 细英文：一个大写英文单词，后面一条下划线一直拉到画面右边。
- 胶囊标签：粉色一段写「形容词 + 地名 + 之旅」这样 6 个字左右，黄色一段写天数「N 天 N 晚」。
- 口号：两行，每行 12–14 个字，第二行往右缩进，句尾一个波浪号。
- 路牌：地名，4 个字左右。

对比：标题的粉和蓝压白底都只有约 2.7:1，靠字特别大特别粗、再加一道橙边撑住，所以字不能变细变小；粉胶囊上的白字约 2.6:1，也偏淡，字要粗；黄胶囊上的黑字约 12:1；白色口号压深蓝天空约 3.5–3.8:1，所以口号背后要是饱和的蓝天，不能是白云。

**装饰**

- 黄色细圆圈 1 个：细线描的圆，只有线、不填色，在小胶囊右边、标题上方的白底上。
- 橙色碎片 1 组：两片尖三角，像炸开的纸屑，在标题左上角。
- 浅蓝波浪 1 道：标题下面，左低右高，上沿是白色的柔和波浪。
- 照片上沿的白色波浪边：照片左上角剪成起伏的弧线，露出白底。
- 白色虚线 1–2 道：细的白色虚线，弯弯地绕在照片右边天空和树上，像旅行路线。
- 黄色波浪条 1 道：底部纯黄色的宽波浪带，左低右高，把一排小照片框起来，小照片之间也用黄边隔开。
- 山形小照片 0–1 张：另一张风景照，上沿剪成山的轮廓、带一道白边，贴在左下。
- 木头路牌 0–1 个：一根木杆上一块箭头木板、一块写地名的木板，立在左下。
- 走路小人 0–1 组：两个白色的走路小人剪影，站在右下的黄色波浪条上。

## 为什么好看

1. 白底托出大标题：上面三成干干净净，只放一行横贯的粉蓝大字和几样很小的贴纸，标题字高是胶囊字的五倍，一眼先读到活动名。
2. 粉、蓝、黄三色串起整张：标题的粉蓝接着浅蓝波浪和蓝天，粉胶囊、黄胶囊再接到底部的黄色波浪条，颜色从上到下来回呼应，满版照片也不散。
3. 波浪边让照片和白底咬在一起：照片上沿剪成起伏的波浪，不是一刀切的直线，上下两段像撕开又拼上，画面有轻快的节奏。
4. 背影带着看：人群背对镜头、举手面对地标，看的人跟着他们一起站到景点前，比正面摆拍更有「到了」的兴奋。
5. 一大几小讲全一趟：大照片给最好看的那一处，底部一排小照片补上吃的、玩的这些别的看点，一张图就看得出这趟能玩好几样。

## 可变范围：跟着活动变

- 大照片：换成这场最好看的地方，人群背对镜头或侧身面对地标、举手欢呼；晴天、深蓝天空；人在照片中下部，上面留出天空写口号。
- 小照片：0–3 张，换成这场别的看点（吃的、玩的、住的）；0 张时黄色波浪条照样留着，只是不框照片。
- 标题：3–6 个字一行，横贯 85–90% 宽；字少时可以像样张一样让后两个字更高，字多就一样高。
- 胶囊标签：粉色一段写主题，黄色一段写天数；资料卡里没有天数就只留粉色一段。
- 口号：0–2 行；没有就把天空整片留给照片。
- 小胶囊、英文手写、细英文的字跟着这场换；英文可有可无。
- 路牌、山形小照片、走路小人：各 0–1 个；路牌写这场的地名，没有就去掉；山形小照片要第二张风景照。

## 容易翻车

- 标题渐变画成彩虹色、或者整行一个颜色：只有粉和蓝两种，相邻的字方向错开；橙色错位边要细，不能变成粗描边。
- 标题变细、变小：粉蓝压白底本来就淡，字不够粗大就看不清。
- 照片上沿切成直线：没了波浪边，上下两段就断开了。
- 口号写在白云上，白字看不见：口号背后要是饱和的蓝天。
- 小照片、路牌、走路小人、山形照片全塞进去，底部挤成一团：小照片最多三张，路牌和山形照片照片够才放。
- 黄色波浪条画成直的色带，或者颜色发橙发暗：它是亮黄 #FCE40C 的波浪。
- 人群正面摆拍、脸被胶囊或路牌挡住。

## 验收要点：出完逐条打勾

- [ ] 上面约三成是白底，标题横贯、约九成宽，超粗方黑体，粉蓝交替渐变、右下有细橙边
- [ ] 标题周围有小胶囊、黄色细圆圈、橙色碎片和英文手写，都很小，不抢标题
- [ ] 标题下有粉色、黄色两段胶囊标签，字一字不差
- [ ] 大照片满宽，上沿是起伏的波浪边，不是直线
- [ ] 人群背对镜头或侧身，在照片中下部，后面是饱和的深蓝天空
- [ ] 口号是白字、写在蓝天上，旁边一道白色虚线（有口号时）
- [ ] 底部一道亮黄色波浪带，框着一排小照片（有小照片时）
- [ ] 没有样张的字、人物和寺庙

# 模板：亲子草原贴纸

**样张**：`assets/样张/亲子草原贴纸.jpg`。用 Seedream 出图时把它放进参考图第一张，照它的版式、配色和装饰出，内容换成这场活动（写法见 SKILL.md「第三步（Seedream）」）。

一句话：晴天草地实拍，一家人在下面野餐，上面黄飘带加白描边的绿色卡通大字，四周贴着白云、兔子贴纸。

适合：亲子游、周末营、露营、草地野餐、农场、自然营地这类户外、一家人一起玩的活动。

这份设计取自旅游营销工作台的自带模板，按 WorkBuddy 自带的混元模型写好了提示词骨架；还没做过还原测试，出完照「验收要点」逐条看。

**照片**：有这场的实拍照片，放进 `image1`（最多 `image1`–`image3`），提示词里写「画面用图一的实拍照片做底」，照片里的人和场景保持原样。没有实拍照片，AI 会照骨架画一个示意画面：交付时要跟用户说清楚“画面里的人和景是 AI 画的示意，不是活动现场照片”，发不发由用户定。

## DNA：换活动也不变

**渲染**：一张满版实拍照片打底，上面贴扁平的卡通贴纸和字。照片是晴天、饱和度高、偏蓝绿：上面是浅蓝天空，中间远处的山林在阴影里偏深蓝，下面近处是阳光下亮绿的草坡和草地。明暗：上三分之一（天空）平均亮度约 194/255，中段约 123（深色山林压着），下段约 131。贴纸都是平涂颜色、轮廓干净，没有立体光影（只有黄飘带带一点折角阴影）。

**构图**

- 照片分三层：上面约 35% 天空，中间一道深色山林（约 y 38–58），下面亮绿草坡和草地。平视略高的中景，远近层次分明。
- 主体：一家三口坐在浅绿格子野餐垫上，在画面下部正中，整组宽约画面一半、高约五分之一，侧身面对面笑着互动，不看镜头；野餐垫上有篮子、水果、小桌。左边一顶白色尖顶帐篷做框，右边缘一丛卡通植物收边。
- 字全部居中，在上半部叠成一竖列：黄飘带 → 口号 → 大标题 → 卖点。大标题和卖点正好压在中间那道深色山林上，白描边和黄字在暗处跳出来；飘带和口号在浅蓝天空上。
- 视线：飘带 → 口号 → 最大的大标题 → 黄色卖点 → 往下落到野餐的一家人 → 右下的小兔子。

层级：大标题 : 口号 : 副标题 : 卖点 ≈ 1 : 0.8 : 0.25 : 0.2。整张三种字：毛笔字（口号）、白描边卡通毛笔字（大标题）、粗黑体（副标题、卖点）。

字的写法（样板）：

- 口号：四个字的亲子口号，可以带谐音（把「同」换成「童」这一类）；两种颜色，前白后黄。
- 大标题：「怎么玩 + 地名」，四五个字。
- 副标题：「地点 + 主题 + 天数」一句，12 个字左右。
- 卖点：三个两三个字的短卖点直接连成一行，中间不加标点。

对比：飘带上深蓝字对黄约 4.9:1；标题绿对白描边约 4.9:1，白描边对深色山林约 11:1（不描边的话，绿字对山林只有 2.3:1，会埋进去）；黄卖点对深色山林约 6–10:1；口号的白字、黄字对浅蓝天空只有 1.5–1.7:1，靠灰投影和字大撑着。

**装饰**

- 黄色立体飘带 1 条：横跨画面宽度的四分之三，两头往后折、折角是橙色阴影，中间微微往上拱。
- 金黄色细线 1 根（#F5D24B，宽约画面宽的 0.5%）：从口号左下绕一个圈，穿过两行大字之间，斜着拉到画面右边，像一根风筝线。
- 扁平卡通贴纸 7–8 样，平涂、轮廓干净：白云 2 朵（白色带浅蓝阴影，边缘圆鼓鼓，口号右边一朵、卖点左边一朵）；右上角一个白色线描太阳（一圈白描边的椭圆光芒）；右下一只白色小兔子（深棕细描边，坐着，扭头朝一家人那边看，脚下几颗黄绿小圆点）；右边缘一丛卡通植物（一根细茎顶着小红花、一枝橙黄叶子、几团橄榄绿圆叶）；帐篷边几朵小雏菊；大标题后面还藏着两个只露出一半的亮面小气球（右边一个黄的、下边一个橙的）。
- 半透明拼音大字 1 行（可选）：白色、字身是横条纹，压在口号和大标题之间、字的后面。

## 为什么好看

1. 字和照片的明暗配好了：上面亮的天空放飘带和口号，中间暗的山林正好垫在大标题和卖点后面，白描边、黄字在暗处跳出来；下面亮绿的草地留给一家人。
2. 真人加卡通，正对亲子的心思：实拍的一家人野餐让家长相信「真的能这样玩」，白云、兔子、植物这些卡通贴纸又把画面变成孩子喜欢的样子。
3. 两行大字一轻一重：上面的毛笔口号讲情绪，下面最大、粗白描边的深绿卡通字讲去哪；深绿和草地同一个色系，靠白边分开，整张颜色统一不乱。
4. 视线一条直线往下：飘带、口号、大标题、卖点全部居中叠成一列，读完正好落到下面野餐的一家人身上。
5. 黄色点睛：飘带、柠檬黄字、金黄细线三处黄，在大片蓝绿里最跳，引着眼睛从上往下读。

## 可变范围：跟着活动变

- 照片：换成这场的户外大场景，草地、营地、农场、湖边、林间空地都行；保持「上面天空、中间一道深色（山林、树林、远山）、下面亮绿草地」三层。照片里没有深色带时，把大标题和卖点背后那一段照片压暗一点。
- 孩子和家长：
  - 亲子活动写「一家人」：一位爸爸或妈妈（三十多岁）带一两个中国小朋友（四到十岁），或者爸爸妈妈和孩子三个人；坐在野餐垫上或在草地上一起玩（分水果、吹泡泡、放风筝、看绘本），侧身面对面笑着互动，不看镜头。
  - 营地、研学写「一群小朋友」：五六个中国小朋友围坐在野餐垫上，一位带队老师蹲在旁边。
  - 衣服鞋子朴素、浅色（白、米、浅蓝、浅黄），没有图案和标志；表情写「笑」「专注」，不写张大嘴。
  - 人在画面下部正中，整组宽约画面一半，高约五分之一（竖版 3:4 里约四分之一）；脸完整，不被字、贴纸和画面边挡住。有这场的实拍就用实拍里的人。
- 道具：帐篷换成这场有的（天幕、野餐桌、风筝、小推车、篮子），放在一侧做框；道具上不出现牌子。
- 大标题：4–6 个字，不换行；口号 3–5 个字，前半白、后半黄。只要一行字时，留大标题（深绿白描边），去掉口号，飘带往下挪一点。
- 副标题：8–14 个字，写地点、天数、年龄段、日期里的两三样。
- 卖点：0–1 行，三个短词。要放两三条长一点的卖点，改成 2–3 个深绿圆角小标签（白字，前面一个白色小圆点，这样排更整齐），竖着排在大标题下面，不压人。
- 贴纸：白云、兔子、植物可以换成和这场有关的小动物、小植物（小羊、小鸭、向日葵、蘑菇），一共 6–8 样，不压人脸、不压字。拼音大字可以不要。
- 竖版（3:4）：照片三层往上收：天空 y 0–33，深色山林 y 33–56，草坡、草地 y 52–100。线描太阳 x 78–100、y 0–12；飘带 x 12–88、y 7–18.5，字在 y 10.5–14；口号 x 19–80、y 19.5–31；大标题 x 8–90、y 32–48.5；卖点 x 33–67、y 50.5–54；白云在口号右边 x 79–94、y 27.5–33，卖点左边 x 0–16、y 50–56；细线 y 29–46；帐篷 x 0–24、y 57–90；一家人 x 28–86、y 71–97；卡通植物 x 84–100、y 55–82；兔子 x 78–87、y 85–95。
- 横版（16:9）：字在左半边、一家人在右半边。字一列居中在 x 27 这条线上：飘带 x 4–50、y 7–24；口号 x 9–45、y 25–43；大标题 x 3–51、y 45–70；卖点 x 11–43、y 73–80；照片的深色山林带落在 y 38–62，垫在大标题后面。一家人 x 50–92、y 58–97；帐篷在一家人后面偏右 x 72–92、y 36–82，被人挡住下半；兔子在一家人左边 x 45–52、y 84–96；线描太阳 x 86–100、y 0–22；白云一朵在口号右边 x 46–58、y 26–36，一朵在一家人上方 x 70–84、y 12–22；卡通植物在右边缘 x 92–100、y 40–80；细线从口号左下绕圈，拉到 x 60 左右收住，不穿过人。

## 容易翻车

- 大标题不加白描边：深绿字埋进深色山林里，看不清。
- 口号的白字、黄字没有投影：在浅蓝天空上发虚。
- 人太大、正对镜头，变成写真；人太小，又看不出是一家人在玩。
- 贴纸超过 8 样，或者压在人脸和字上，变乱。
- 卡通贴纸画出立体光影、写实毛发，和扁平的白云、兔子不是一套。
- 拼音字母拼错：没把握就不放。
- 衣服画出图案标志，道具（收音机、包、水杯）上冒出牌子。
- 大标题写成带圆点花纹的字：应该是飞白划痕，不是圆点。

## 验收要点：出完逐条打勾

- [ ] 满版晴天户外实拍，上天空、中间一道深色山林、下面亮绿草地
- [ ] 一家人（或一群小朋友）在下部正中一起玩，不看镜头，脸完整，衣服鞋子没有图案和标志
- [ ] 上部有一条两头折回的黄色飘带，上面是深蓝字
- [ ] 最大的一行是深绿卡通字、带粗白描边，压在深色山林上
- [ ] 口号（有的话）是毛笔字，前白后黄，带灰投影
- [ ] 卡通贴纸 6–8 样，平涂、不压人脸和字；有一根金黄细线
- [ ] 没有别家海报的字和人物，道具上没有牌子

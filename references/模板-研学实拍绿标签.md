# 模板：研学实拍绿标签

一句话：孩子户外实拍铺满整张，蓝天上压白色胖胖的大标题配一条绿色色条，白纸条写卖点，右下角绿纸块写价格。

适合：研学旅行、夏令营、多日营、户外营地，孩子在户外动起来、要写清天数和价格的活动。

这份设计取自旅游营销工作台的自带模板，按 WorkBuddy 自带的混元模型写好了提示词骨架；还没做过还原测试，出完照「验收要点」逐条看。

**照片**：有这场的实拍照片，放进 `image1`（最多 `image1`–`image3`），提示词里写「画面用图一的实拍照片做底」，照片里的人和场景保持原样。没有实拍照片，AI 会照骨架画一个示意画面：交付时要跟用户说清楚“画面里的人和景是 AI 画的示意，不是活动现场照片”，发不发由用户定。

**WorkBuddy 的标识**：WorkBuddy 出的图右下角会盖「AI生成 WORKBUDDY」。价格块照样放右下，但价格的字写在块的左上部分，块最右下那一角空着留给标识，不放字。

| 项 | 内容 |

## DNA：换活动也不变

**渲染**：真实摄影，晴天户外，阳光从右上方斜照进来，有一团柔和的光晕；色调清新：天空是饱和的蓝，草地是鲜亮的黄绿。整张压着一层很淡的水彩纸纹理，天空里看得到细细的纸面颗粒。纸条、色条、价格块都是平涂，没有投影；纸条边是撕开或剪开的不齐的边。明暗：上三分之一平均亮度约 170/255（蓝天），中间约 178，下面约 133（草地和价格块偏暗）。

**构图**

- 照片满版：上面约四成（y 0–38）是蓝天和淡云，标题写在天上；下面六成是草地上的孩子。
- 焦点：两个孩子背对镜头往画面深处跑，每个约占画面宽的三成，从头顶 y 39 到脚 y 85；低机位、广角，前景草叶有点虚，孩子清楚，远处是这场的特色景物。
- 视线：从上往下：英文地名条 → 大标题 → 绿色色条 → 左边两条卖点 → 绿箭头指过去的右边卖点 → 右下价格。孩子往里跑的方向也把视线带进画面。
- 平衡：标题组居中；下面卖点左二右一错开，价格块压右下、口号纸条压左下，对角呼应。

层级：大标题 : 价格数字 : 色条字 : 卖点 : 英文地名 : 口号 ≈ 1 : 0.43 : 0.4 : 0.22 : 0.18 : 0.13。整张三种字：胖胖的手写感粗体（标题、色条、价格数字）、圆润粗黑体（卖点、口号、人数日期）、英文（空心无衬线和手写衬线 HELLO）。

字的固定写法：

- 色条：「活动类型 + 天数」，比如「研学 N 日游」。
- 英文地名条：目的地的英文或拼音，全大写，字母空开。
- 卖点：3 条，每条 5–8 个字的名词短语，是这场去的地方或上的课。
- 口号：两行，第一行短（5–6 个字）、第二行长（9–10 个字），是一句俏皮话。
- 价格块：第一行「数字 + 元/人」，第二行「N 人起 | 出行时间」。

对比：白色标题压中蓝天空约 2.5–2.7:1，靠字又大又胖撑住，所以背后不能是白云；白字压标签绿约 2.8:1，色条字也要粗；卖点的黄绿字压白纸约 2.3:1，近看清楚、远看偏淡，字不能再小、不能再细。

**装饰**

- 绿色细线 1 条：深绿 #2A960C，线宽约画面宽的 0.3%，从左边缘进来，在标题左下绕一个小圈，从色条后面穿过，再从色条右边出来往右上飘出画面。
- 小叶子 2 片：深绿，一片在画面左边缘只露一半（y 8–13），一片在色条右上角。
- 黑色手绘箭头 1 个：马克笔线，从色条右下角弯出来指向右下，箭头头是两笔勾出来的。
- 亮绿粗箭头 1 个：粗的弯箭头，在右边卖点纸条上方，指向它。
- 白色细线 2–3 道：绕着孩子的细白线，像随手画的圈，把左边纸条、口号纸条连起来，不穿过孩子的脸。
- HELLO 对话框 1 个：黑色细线椭圆，带一个小尾巴。
- 底边撕纸：浅薄荷绿撕边纸压在底边左半，高约画面的 5%。

## 为什么好看

1. 背影带着走：孩子背对镜头往深处跑，看的人跟着孩子的视线进到画面里，比正面摆拍更有「出发去探索」的劲。
2. 天空当标题板：上面四成留给蓝天，白色胖字直接写在天上，不用另加底板，整张通透。
3. 一族绿串起来：色条、价格块、卖点字、叶子、细线都是绿，和草地呼应，满版照片上的字也成了一套。
4. 信息分层清楚：最大的是活动名，其次是色条上的「研学几日游」和价格，卖点用纸条小字绕在孩子身边，家长一眼看到去哪、几天、多少钱。
5. 纸条斜贴、手绘箭头和白线，把一张正经的实拍做出了手账的轻松。

## 可变范围：跟着活动变

- 照片：换成这场的晴天户外实拍，孩子在动：背影往里跑最好；没有的话用侧面在玩、在看的。孩子在中下部，头顶上面留出约四成天空；远处最好有这场的特色景物。
- 标题：2–4 个字，宽 43–70%，不换行；字多时宽度到 70% 为止，字高跟着缩到 12%。
- 色条：一行，字数 4–7 个；色条宽跟着字走，比标题两边各宽出 3–6%。
- 卖点：0–3 条；2 条时左边只留一条、右边一条；0 条时去掉纸条和绿箭头，白线留 1–2 道。
- 口号：0–2 行；没有就去掉口号纸条。
- 价格：资料卡里有价格才放；没有价格时，大字换成出行日期（「7–8 月」这样），第二行写人数或报名时间；都没有就去掉价格块，口号纸条挪到右下。
- 英文地名条：换成这场的目的地；也可以换成正文里那种用银色别针别住的斜卡片（绿底黑字，斜 10° 左右），放在同一个位置。HELLO 对话框可有可无。
- 竖版 3:4（整体往上收一点）：英文地名条 x 27、y 3.5、宽 46、高 4.5；HELLO x 10、y 4.5、宽 13、高 5；大标题 x 27、y 9、宽 46、高 15；绿色色条 x 24、y 24、宽 52、高 9；黑色手绘箭头 x 66、y 31、宽 14、高 5；左边卖点纸条 x 0、y 55、宽 38、高 10；右边卖点纸条 x 62、y 66、宽 38、高 8；绿色粗箭头 x 76、y 58、宽 12、高 7；口号纸条 x 0、y 76、宽 36、高 10；价格块 x 50、y 78、宽 50、高 22；底边撕纸 x 0、y 95、宽 50、高 5；孩子在 x 12–76、y 38–86。
- 横版 16:9（字压左边，孩子在中间偏右）：照片满版，孩子在 x 36–72、y 22–95 往里跑，左上留出天空；英文地名条 x 5、y 6、宽 30、高 7；HELLO x 36、y 6、宽 9、高 9；大标题 x 5、y 14、宽 32、高 27；绿色色条 x 4、y 41、宽 36、高 13；左边卖点纸条 x 0、y 58、宽 32、高 20；绿色粗箭头 x 80、y 41、宽 9、高 8；右边卖点纸条 x 68、y 50、宽 32、高 10；口号纸条 x 0、y 82、宽 30、高 13；价格块 x 72、y 64、宽 28、高 36；底边撕纸 x 0、y 93、宽 72、高 7。

## 容易翻车

- 标题背后是白云或很亮的天，白字看不见：标题一定落在饱和的中蓝天空上。
- 孩子正脸摆拍、看镜头，没了往里跑的劲；或者孩子太小、挤在远处。
- 卖点纸条、价格块压住孩子的脸和身体。
- 价格块画成正圆、圆角方块，像超市价签；它是切角的绿纸，伸出画面右边和底边。
- 绿色用得太杂：主绿只有一个 #5FAC0A，加黄绿字、亮绿箭头和深绿细线，不再加别的绿。
- 编价格、人数、日期：资料卡里没有就不放。
- 手绘线、箭头太多变乱：黑箭头 1 个、绿箭头 1 个、白线 2–3 道。

## 提示词骨架

客观描述，不写「要求」；照片铺满整张，先写照片，再写压在照片上的字和纸条；每段字单独一句「写着…」，写清位置和相对大小；{} 里是每场要填的，用不上的那一块整句删掉。

## 验收要点：出完逐条打勾

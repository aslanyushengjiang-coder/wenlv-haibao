# 模板：蓝色撕纸拼贴

**样张**：`assets/样张/蓝色撕纸拼贴.jpg`。用 Seedream 出图时把它放进参考图第一张，照它的版式、配色和装饰出，内容换成这场活动（写法见 SKILL.md「第三步（Seedream）」）。

一句话：一大张钴蓝色纸被横着撕开，口子里露出整条风景照；带白边的人物抠图从风景里探出来，旁边贴浅灰皱纸标签和斜贴的白纸条，最顶和最底各压一条点缀色撕纸

适合：多日营、远途研学：雪山、湖海、海岛、古城、草原这类有风景可拼的目的地。

这份设计取自旅游营销工作台的自带模板。2026-10-24 用腾讯云 Seedream 5.0 Pro 按下面的提示词骨架填活动资料出过竖版，中文字全对、版式到位；出完照「验收要点」逐条看。

**照片**：有这场的实拍照片，放进参考图（Seedream 走 `ref_paths`），提示词里写「画面用图一的实拍照片……原样保留，不重画、不加人」，人才像真的。没有实拍照片，AI 画的是示意，人物写成背影、侧身或远景，交付时说清楚“画面里的人和景是 AI 画的示意”。不要让 AI 照着某个真实地名去画地标，冒充去过。

## DNA：换活动也不变

**渲染**：纸张拼贴。底是一大张平涂的饱和钴蓝色纸（样张1 #3458B1，纸面有很浅的皱褶纹）。纸边都是手撕的：撕口露出一道白色纸芯，宽约画面高的 1–2.5%，毛糙不齐、上下起伏 1–3%，压在下面一层上有很淡的投影。风景和抠图都是真实照片，带一层细颗粒；抠图外面留一圈白边（宽约画面宽的 0.6–1.2%），像用剪刀一段段直线剪下来的贴纸，不是光滑的描边。抠图里总有一两样做成黑白或网点（样张1 的人物和话筒是网点，样张2 的牛和老楼是黑白，样张3 的椰子树和教堂是黑白），其余是彩色。三张都有粗纸或皱纸的质感：样张1 是标签条和上下两条点缀色纸，样张2 是山的抠图上压着一层皱纸纹，样张3 是带细噪点的灰色边框。

**构图**

- 三张都是字在上、拼贴在下：标题和标签都在画面上半（样张1 在 y12–37），风景和抠图从画面中部一直拼到底边。
- 层次（从下往上）：钴蓝纸 → 蓝纸中部被横着撕开，口子里露出一整条横贯全宽的风景照（样张1 从 y34 到 y79）→ 上下两道白色撕口把风景照夹住 → 风景照和下方蓝纸上散贴带白边的抠图 → 最上面是标签条、白纸条和字；画面最顶和最底各压一条点缀色皱纹纸。
- 焦点：下半部一个最大最近的主体抠图，从风景里探出来、压住下面一层纸（样张1 是右下的人物，宽约画面一半、高约三分之一，下半身压住下方蓝纸；另外两张是白房子、灯塔）；第二焦点是大标题。
- 视线：大标题 → 右下方的标签条 → 斜贴的白纸条 → 右下的人物 → 左下的地标抠图。
- 平衡：标题横跨全宽；下半部人物压右、地标压左，中间露出风景照里的雪山和湖面。

层级：大标题 : 地名小字 : 标签字 : 卖点字 ≈ 1 : 0.4 : 0.2 : 0.2。整张三种字：特粗标题黑体、常规无衬线黑体、手写细英文。三张的大标题都是特粗、方块感的粗字，颜色跟着背后的底走：直接压在蓝纸上用白字（样张1），放进米白长条或灰纸边框里用黑字（样张2、3）。

字的固定写法（三张都有）：

- 标签条：里面总有地点和天数，样张1 是一条地点、一条天数和玩法（「云南大理」「3日精华游」；另外两张是「重庆→云南」配「YUNNAN&5DAYS」、「北海&涠洲岛3日游」）。
- 一处英文点缀：地名拼音或「N DAYS」，手写、花体或粗大写（Yun Nan / 3 Days、Yunnan tourism、PLAY ISLAND）。
- 卖点：口语短句，带标点和语气（「去，大理！呼吸每日新鲜空气~」）；或者三个三字短语用「·」隔开（「观雪山·游洱海·感人文」）；或者放进标签里的四字短语（「海岛美景」「海鲜畅吃」）。

**装饰**

- 撕口：样张1 一共五道：顶部点缀色纸条下沿、风景照上下两道、底部点缀色纸条上沿、标签后面一小片皱纸。撕口都是毛糙的白色纸芯，不是整齐的白线或波浪线。
- 长尾夹：一只银色金属长尾夹，斜着夹住标签条的右上角。
- 网点纸：一片撕下来的黑白网点纸贴在右边缘，往下渐淡。
- 斜贴白纸条：三条，宽约画面高的 3%，两端剪平，跟着斜度微微弯，像贴上去的纸胶带。
- 抠图白边：所有抠图都有，剪刀剪出的直线折角。
- 三张共有的是撕口、抠图白边和黑白小标签；长尾夹、网点纸是样张1 的，样张2 用的是白色细线网格小贴片，样张3 用的是带细彩色描边、四角带小圆点或小方块的「选中框」标签（见「可变范围」）。

## 为什么好看

1. 一大块钴蓝压住热闹：拼贴的东西再多，底下都是同一块饱和的蓝，画面不散；白字压在蓝上约 6.5:1，标题不用描边也跳出来。
2. 撕口造出前后层：蓝纸在前、风景在后，白色纸芯把两层分得清清楚楚，平面的拼贴有了纵深，像真的把纸撕开往里看。
3. 人物出框：主人物从风景照里探出来、压到下面的蓝纸上，是全图最大最近的东西，和顶部大标题一上一下撑住画面。
4. 一种点缀色点亮整张：只用一种和蓝反差大的颜色，一上一下各放一处（样张1 是最顶和最底两条纸），把视线框在中间；蓝色压得太沉时由它提亮。
5. 层级拉得开：标题字高约是标签字的 5 倍，先读到名字，再读地点天数，最后读斜贴的卖点短句。

## 可变范围：跟着活动变

- 点缀色：一场只用一种，挑和这场照片最搭的：雪山、蓝天、湖水多的用黄（#EBDD35，样张1）；黄昏、沙漠、暖色多的用橙（#F57505，样张2）；海岛、草地、绿植多的用亮绿（#81D243，样张3）。用在最顶和最底两条撕纸条上；也可以改成用在一条标签和一两道细线上，加起来不超过画面的十分之一。
- 钴蓝：在 #3458B1 到 #0446A8 之间，风景照偏亮时取深一点。
- 风景照：换成这场目的地的风景（雪山、湖海、海岛、古城、草原），横着铺满整条；天和水偏冷蓝最好。也可以照样张2：把几座山、几片景沿着轮廓撕下来，一层层叠着从画面中部铺到底，每层都留白色撕口。
- 主人物：换成这场的中国小朋友（一两个，或者一家人），彩色抠图带白边，全身或大半身，动作要大（举手、张开手臂、跳起来、挥手），从风景照里探出来、压住下方蓝纸；脸完整、看得清。样张1 的人物做成网点，孩子不做网点。
- 小抠图：两三样和这场有关的小东西（样张是海鸥、话筒、宝塔、老楼、牛、灯塔、椰子树、小汽车），带白边，其中一两样做成黑白或网点；地标放左下、站在底部纸条上。
- 标签条：两条，一条地点、一条天数和玩法或日期，每条 4–8 个字。也可以照样张3：一条黑底白字、一条白底黑字，或者用「选中框」标签。
- 卖点：0–3 条，写在斜贴的白纸条上，每条 6–14 个字的口语短句；没有卖点就只留一条纸条写一句口号，或者全去掉。宁少不编。
- 标题：4–6 个字一行，白字直接压蓝纸，宽约 85–90%；7–10 个字分两行，每行放进一条米白长条（#FBF8F6）、黑字，第二行比第一行长（样张2 的做法）。
- 地名小字和英文点缀：各一处，没有就去掉；英文用地名拼音或「N DAYS」，手写细字跟在标签条边上。
- 长图里能用的：拍立得（白边、下边更宽的小照片，斜贴、长尾夹夹住，放这场的实拍，1–2 张，贴在风景照上沿或下方蓝纸上）；一段弯曲的柏油路（白色虚线中线）加一辆小车或电瓶车，放在下方蓝纸上代替地标；白色细线网格小贴片代替网点纸。
- 竖版 3:4（主骨架）：长图头图偏高（1:1.8），压进 3:4 时标题、标签、人物照宽度算大小不变，所以占的高度比例变大；腾地方的办法是风景照带变矮约四分之一、下方蓝纸变窄、卖点纸条挤近一些；话筒、地标注释和第二只海鸥去掉。分区如下表。
- 横版 16:9：标题和标签在上，风景照带横在下半部，人物在右边、头顶探出风景照上沿；网点纸、地标注释、话筒去掉，海鸥留一只；风景照带下沿直接接底部纸条，中间只露一窄条蓝纸。分区如下表。

## 容易翻车

- 只写「蓝色背景」，会画成浅天蓝或渐变蓝：要写「饱和的钴蓝色纸」，并写它的边是撕开的。
- 风景照写在一串小东西中间，会被画成一张小照片：先写蓝纸、再写横贯全宽的风景照带，最后写贴在上面的东西。
- 撕口写得含糊，会画成整齐的白描边或波浪线：要写「撕开的、毛糙的白色纸芯」。
- 点缀色一多就乱：一张只用一种，别黄橙绿都上。
- 抠图太多太碎：主人物一个、小抠图两三样就够；每样都写位置，反而丢东西、放错地方。
- 孩子做成网点或黑白，家长看不清孩子的脸：网点、黑白只用在小道具上。
- 标题加描边、投影或渐变，剪贴的平面感就没了。

## 提示词骨架

## 验收要点：出完逐条打勾

- [ ] 底是一大块饱和的钴蓝色纸，不是浅天蓝、不是渐变
- [ ] 一整条风景照横贯全宽，上下两道撕口都露出毛糙的白色纸芯

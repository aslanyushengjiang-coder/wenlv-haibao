# 活动海报 Skill（wenlv-haibao）

给亲子游、研学、营地机构用的 AI Skill：说一句话，WorkBuddy 自己画一张竖版活动海报，能直接发朋友圈和社群。

- 在 WorkBuddy 里用它自带的画图出图，**不用配 Key**，一张大约扣 5 个 WorkBuddy 积分。
- 先去知识库找这场活动的资料，缺日期、地点、年龄会一项一项问，资料里没有的不上海报。
- 出完逐字核对日期、地点、价格；字错了自动重出一次。
- 画面里的人像手机随手拍的：内置一段锁死的真实感提示词，防油光、磨皮和 AI 脸；没有实拍照片时，人物画成背影、侧身或远景。

## 安装

在 WorkBuddy 里新建任务，把这句话发过去：

```text
帮我安装 wenlv-haibao 这个 Skill，地址是 https://github.com/aslanyushengjiang-coder/wenlv-haibao 。装好以后告诉我装好了没有。
```

## 用法

```text
用活动海报Skill，给【活动名】做一张竖版活动海报。
```

想指定样子，就点名模板：

| 模板 | 长什么样 | 适合 |
| --- | --- | --- |
| 满版照片大白字 | 照片压暗铺满整张，超粗白色大标题，右边三条打勾卖点 | 户外、运动、动手类活动 |
| 研学绿标签 | 孩子户外实拍铺满，蓝天上白色胖胖大标题加绿色色条 | 研学、夏令营、多日营 |
| 草原贴纸 | 晴天草地上一家人野餐，黄飘带加绿色卡通大字，卡通贴纸 | 亲子游、周末营、露营 |
| 风景剪贴 | 蓝天上粗毛笔大字，下面一长条带白边的风景照片剪贴 | 多日营、跨城研学、城市漫游 |
| 蓝色撕纸 | 钴蓝纸被撕开露出整条风景照，带白边的孩子抠图 | 多日营、远途研学 |
| 绿剪报 | 橄榄绿底，荧光黄英文大字，复古电视、相机剪报拼贴 | 城市游、跨城研学 |
| 黑字涂鸦 | 晴天户外实拍，黑色超粗大字配黄色手绘线 | 户外动手、自然探索 |
| 渐变大字 | 粉蓝渐变大字，波浪边框住照片 | 研学营、海岛湖边 |
| 冰雪卡通 | 白色撕纸标题卡配卡通贴纸，城市地标晚霞实拍，雪山滑雪剪贴 | 冬季营、冰雪研学 |

有自己的实拍照片，放进当前文件夹，说「用这几张照片做底」，效果更好。没有照片也能出，画面是 AI 画的示意，交付时会提醒。

## 推荐：接上 Seedream（腾讯云）

想让海报的中文字更准、人更像真的，可以请字节的 Seedream 5.0 Pro 画：在腾讯云 TokenHub 微信扫码办一把钥匙（API Key），打开 Seedream 的后付费，然后跟 WorkBuddy 说：

```text
用活动海报说明书，帮我接上 Seedream 画图。钥匙是：【你的钥匙】
```

以后说「请 Seedream 画」就行。竖版一张 0.6 元，从你自己的腾讯云账户扣，约 80 秒出图。需要电脑上有 Python 3（WorkBuddy 自带一个）。钥匙只保存在本机，不会写进任何文件或回复里。

## 可选：用 APIMART 出图

没有自带画图工具的 AI 助手，或者想让字更准，可以接 APIMART 的 gpt-image-2.5 模型：配一次自己的 Key，以后在句子后面加「用APIMART」。需要电脑上有 Python 3。Key 只保存在本机，不会写进任何文件或回复里。

## 文件

- `SKILL.md`：执行说明
- `references/`：九个模板的设计文件、五种快速风格、真实感提示词（`真实感照片.md`）
- `assets/样张/`：每个模板一张样张，Seedream 出图时当参考图，照它的样子换成你的活动
- `assets/人脸参考/`：一个男孩、一个女孩的真实照片（Pexels 免费图库），没有自己活动照片时当人脸参考
- `scripts/seedream_tokenhub.py`：腾讯云 TokenHub Seedream 出图工具（只用 Python 标准库）
- `scripts/image2_5_apimart.py`：APIMART 出图工具（只用 Python 标准库）
- `templates/`：APIMART 请求样例、空的 APIMART 和腾讯云钥匙配置模板
